# Financial Misinformation and the FOMO-Conscientiousness Interaction

Tests whether FOMO and conscientiousness interact to predict financial misinformation sharing. Extends Prof. Hemant Kakkar's framework on political ideology, conscientiousness, and fake news sharing into a financial context, with FOMO substituted for ideology.

## Status
Data collection in progress. Target: about 300 respondents.

## Method
- Conscientiousness: BFI-2-XS
- FOMO: Przybylski FOMO scale
- Five financial misinformation vignettes, each rated for share-likelihood and truth-belief
- Mixed-effects model, ratings nested within respondent
